# 옥수수손오공

Phaser 3, TypeScript, Vite 기반의 2D 횡스크롤 액션 웹게임입니다. 초등학교 1~2학년이 서유기 이야기를 따라가며 플레이할 수 있도록 만들었습니다. 스마트폰·태블릿에서는 홈 화면에 추가해 앱처럼 전체 화면으로 실행할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 또는 Vite가 출력한 주소를 엽니다. 같은 와이파이의 태블릿에서는 Vite가 출력한 Network 주소로 접속합니다.

## 조작

- 이동: `←/→` 또는 `A/D`
- 점프: `↑` 또는 `W`
- 공격: `Space Bar`
- 동료 스킬: 합류한 동료의 왼쪽 얼굴 버튼 또는 `1`(삼장법사) · `2`(저팔계) · `3`(사오정). 버튼에 다시 쓸 수 있을 때까지 남은 초가 표시됩니다.
- 잠깐 멈춤: `Esc` 또는 `P`, 화면 오른쪽 위 ⏸ 버튼
- 대화 넘기기: 화면 터치, `Enter` 또는 `Space` (첫 번째 누름은 글자를 모두 보여 주고, 두 번째 누름은 다음 장면으로)
- 터치 화면: 아래쪽 ◀ ▶ 버튼으로 이동, 점프·공격 버튼. 손가락을 떼지 않고 버튼 사이를 미끄러져도 되고, 공격 버튼을 누르고 있으면 계속 휘두릅니다.
- 근두운: 2장부터 공중에서 점프를 한 번 더 누르면 구름을 타고 한 번 더 뜁니다(1장 끝에 수보리 조사에게 배움).

## 어린이를 위한 설계

- 점프 판정이 너그럽습니다. 발판에서 막 떨어진 순간이나 착지 직전에 누른 점프도 인정합니다.
- 1장에서는 걷기·점프·공격 방법이 버튼 그림과 함께 차례로 나옵니다(터치 기기는 버튼, 키보드는 키 이름으로 안내).
- 장마다 지형이 다릅니다. 올라서는 디딤돌과 아래로 지나가는 선반 두 종류만 쓰며, 가시·물 위에는 디딤돌 다리를 놓아 실수로 걸어 들어가지 않게 했습니다. 보스 구역에는 피할 수 있는 선반만 둡니다.
- 옥수수 코인은 발판 위와 출발 지점에 있습니다. 클리어하면 별 하나, 코인 절반이면 별 둘, 모두 모으면 별 셋입니다.
- `장 고르기`에서 지금까지 도착한 장을 다시 하며 별을 더 모을 수 있습니다. 다시 해도 저장된 여행 진행은 뒤로 가지 않고, 그 장 시점에 합류한 동료만 따라옵니다. 이미 깬 장에서는 대화창에 `건너뛰기` 버튼이 나옵니다.
- `요괴 도감`: 물리친 요괴 42종(보스 9종 포함)이 이름과 한 줄 소개와 함께 모입니다. 처음 물리치면 `요괴 도감에 새로 등록!` 알림이 뜹니다. 만나지 못한 요괴는 그림자와 `???`로 보입니다. 새 여행을 시작해도 도감은 남습니다.
- 화면 위의 길 막대에서 손오공 얼굴이 깃발(목표)까지 움직여 남은 거리를 보여 주고, 보스가 있는 곳도 표시합니다.
- 공격이 맞으면 별 조각이 튀고, 일반 요괴는 살짝 밀려납니다. 보스를 때리면 화면이 살짝 흔들립니다.
- 일시 정지 메뉴에서 `이 장 다시 하기`를 고를 수 있습니다.
- 동료가 말을 겁니다. 가시·물·번개·늪·바람이 다가오면 조심하라고 알려 주고, 보스가 보이면 응원하고, 코인을 모두 모으면 칭찬합니다. 하트가 2개 이하로 줄면 장마다 한 번, 동료가 하트 2개를 채워 줍니다(혼자보다 함께).
- 삼장법사(6장부터): 하트 2개 회복과 6초 안에 공격 한 번을 막는 보호막. 재사용 18초.
- 저팔계(7장부터): 바라보는 방향으로 갈퀴 돌진, 각 일반 적에게 피해 2·보스에게 피해 1. 재사용 9초.
- 사오정(8장부터): 물결로 각 적에게 피해 1, 5초간 물 피해·늪 감속·바람 밀림 보호. 재사용 12초.
- 동료 스킬과 재사용 시간은 대화·일시 정지 중 멈춥니다. 구름 부적을 다 써 체크포인트에서 재시도해도 남은 재사용 시간과 보호 효과를 이어갑니다. 앞 장을 다시 할 때는 그 장에 이미 합류한 동료만 호출할 수 있습니다.
- 장 안에서 30분을 놀면, 다음 클리어 화면에서 잠깐 쉬어 가자고 권합니다(`쉬었다 올게요` / `조금만 더 할래요`). 장 도중에는 끊지 않습니다.
- 구름 부적(추가 목숨) 2개. 모두 쓰면 장의 처음이 아니라 마지막 이야기 지점(체크포인트)에서 다시 시작하고, 이미 본 대화와 모은 코인은 유지됩니다.
- 대화는 한 글자씩 나타나며, 대화창이 열린 직후의 연타로 이야기를 놓치지 않도록 잠깐 입력을 무시합니다.
- 체력은 하트, 남은 목숨은 구름, 합류한 동료는 얼굴로 표시해 글을 몰라도 상태를 알 수 있습니다.
- 위험 지형에는 이름표가 붙고, 보스의 번개 공격 전에는 `!` 경고가 나타납니다.
- 처음 화면의 `Enter`는 저장된 여행을 이어 갑니다. `새 여행`은 기록을 지우기 전에 한 번 더 묻습니다.
- 효과음과 배경음악은 처음 화면과 일시 정지 메뉴에서 따로 끌 수 있습니다. 일시 정지 중에는 음악이 작아집니다.

## 이야기 구성

1. 탄생의 옥수수밭: 화과산으로 떠나는 조작·코인 수집 모험
2. 혼세마왕의 동굴: 친구들을 지키기 위한 첫 보스전
3. 용궁의 여의봉: 수문장을 이기고 황금 여의봉 획득
4. 천궁의 추격전: 이랑진군의 번개를 피해 20초 생존, 부처님 손바닥
5. 오행산과 삼장법사: 관음보살의 약속, 스승을 만나 여행 시작
6. 고로장과 저팔계: 저팔계를 진정시키고 동료로 영입
7. 유사하의 사오정: 사오정의 이야기를 듣고 동료로 영입
8. 황풍대왕의 바람산: 거센 돌풍을 뚫는 보스전
9. 호선봉의 어둠숲: 돌진 공격의 빈틈을 찾는 보스전
10. 진흙 요괴의 늪: 느려지는 늪을 건너는 협동의 장
11. 천축국의 마음 거울: 그림자 손오공과의 마지막 전투
12. 불경과 깨달음의 귀환: 부처님에게 불경을 받아 고향으로 귀환

각 장은 책장을 넘기듯 징 소리와 함께 장 제목 카드로 시작합니다. 시작·완료 대화와 길 중간의 이야기가 있고, 보스가 있는 장에는 만남과 해결 대사도 연결됩니다. 원숭이 친구, 동해 용왕, 관음보살이 이야기 속 장소에 직접 등장합니다. 5~7장에서 합류한 동료들은 이후 장에서 손오공을 따라다니며, 장을 마칠 때마다 화과산에서 천축국까지의 여행 지도에 현재 위치가 표시됩니다.

원작의 탄생·수렴동·수보리 조사(일흔두 가지 변신과 근두운)·동해 용궁·천궁 소동·부처님 손바닥·오행산·관음보살·동료 합류·불경 귀환을 어린이 눈높이로 재구성했습니다. 옥수수에서 태어나는 설정, 용궁 수문장 시험, 후반의 숲·늪·마음 거울은 게임의 창작 각색입니다. 원작의 모든 사건을 재현하는 게임은 아닙니다.

## 배경음악

음원 파일 없이 Web Audio로 연주합니다. 내려받을 용량이 없고 저작권 문제도 없습니다. 곡은 `src/audio/songs.ts`에 숫자 악보(1 2 3 5 6 = 도 레 미 솔 라)로 적혀 있어 고치기 쉽습니다.

- 우리 민요처럼 5음계를 쓰고, 악기는 대금(피리)·가야금(뜯는 소리)·편종(종)·북·목탁 소리를 흉내 냅니다.
- 장마다 분위기가 다른 곡: 1장 옥수수밭은 통통 튀는 가락, 2장 동굴은 낮고 조심스러운 단조, 3장 용궁은 물방울 같은 종소리, 4장 추격전은 빠른 북, 5장 오행산은 느린 피리, 6장 고로장은 신나는 마을 춤, 7장 유사하는 흐르는 가야금, 8장 황풍산은 바람 소리 심벌, 9장 어둠숲은 드문드문 울리는 종, 10장 늪은 무거운 걸음, 11장 마음 거울은 엄숙한 종, 12장 천축국은 평화로운 피리.
- 처음 화면에는 손오공 주제가가 나옵니다. 클리어 화면에서는 같은 가락이 잔잔하게, 엔딩에서는 종과 북을 더해 크게 연주됩니다.
- 보스가 가까워지면 전투 북과 낮은 반복음이 더해지고, 보스를 물리치면 사라집니다.
- 장이 바뀔 때는 곡이 부드럽게 겹쳐 넘어갑니다. 화면이 꺼지거나 다른 앱으로 가면 소리가 멈춥니다.
- 브라우저 규칙상 첫 터치(또는 키 입력) 뒤에 소리가 나기 시작합니다. iPhone은 무음 스위치가 켜져 있으면 소리가 나지 않을 수 있습니다.

## 스마트폰·태블릿 웹앱

- `manifest.webmanifest`와 아이콘으로 홈 화면에 설치할 수 있고, 가로 전체 화면으로 실행됩니다.
  - iPhone·iPad(Safari): 공유 버튼 → `홈 화면에 추가`
  - Android(Chrome): 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- 브라우저에서 실행할 때도 터치 기기에서는 시작 버튼을 누르면 전체 화면으로 전환합니다(지원하는 기기만).
- 세로로 들면 `기기를 옆으로 눕혀 주세요` 안내가 나오고 게임이 멈춥니다. 다시 가로로 돌리면 일시 정지 메뉴에서 이어 합니다.
- 다른 앱으로 전환하거나 화면이 꺼지면 자동으로 일시 정지됩니다.
- 서비스 워커(`public/sw.js`)가 한 번 받은 파일과 12장의 배경을 저장해 두므로, 이후에는 인터넷 없이도 실행됩니다. 기기가 데이터 절약 모드면 배경 미리 받기는 건너뜁니다.
- 노치·홈 표시줄 영역을 피하고, 확대·당겨서 새로고침·길게 눌러 메뉴 열기를 막았습니다.
- 게임 화면 폭이 화면 비율(16:9~19.5:9)에 맞춰 넓어져, 긴 폰에서도 좌우에 검은 띠가 생기지 않습니다. 배경은 늘어나지 않게 위아래를 조금 잘라 채웁니다.
- 저사양 태블릿을 위해 그리기 비용을 줄였습니다. 둥근 버튼·하트·패널처럼 잘 바뀌지 않는 도형은 한 번만 그려 이미지로 쓰고(`src/ui/bake.ts`), 체력·진행 막대는 단순한 사각형으로 바꿨습니다. 보스전 한 프레임의 그리기 시간이 3.2 ms → 0.36 ms(CPU를 4배 느리게 해도 18.9 ms → 1.7 ms)로 줄었습니다.
- 학교 기기처럼 저장소가 막혀 있어도 게임은 실행되며, 이때 진행 기록은 창을 닫을 때까지만 유지됩니다.

## 구조

- `src/game/data/stages.ts`: 전체 스테이지 데이터(목표, 적, 지형, 이야기 속 등장인물)
- `src/game/data/story.ts`: 12장 서사와 여정·보스 대사
- `src/game/data/character-art.json`: 48개 캐릭터 이미지 매핑
- `src/game/StageManager.ts`: 진행도, 여의봉 강화, 동료 상태 관리
- `src/game/storage.ts`, `src/game/Settings.ts`: 안전한 저장소 접근, 효과음 설정
- `src/scenes/StageScene.ts`: 데이터 기반 공통 스테이지, 장 제목 카드, 체크포인트, 조작 안내, 별
- `src/scenes/ChapterSelectScene.ts`: 장 고르기
- `src/scenes/BestiaryScene.ts`, `src/game/data/bestiary.ts`: 요괴 도감과 요괴 소개
- `src/scenes/PauseScene.ts`: 일시 정지 메뉴
- `src/scenes/StageClearScene.ts`: 스테이지 클리어와 여행 지도
- `src/scenes/EndingScene.ts`: 엔딩 화면
- `src/entities/Player.ts`: 플레이어 이동, 너그러운 점프, 공격
- `src/entities/Enemy.ts`, `src/entities/BossEnemy.ts`: 적과 보스의 특수 공격
- `src/ui/DialogueBox.ts`: 대화창(한 글자씩 표시, 인물 초상)
- `src/ui/MobileControls.ts`: 터치 조작
- `src/ui/Button.ts`: 큰 터치 버튼
- `src/ui/bake.ts`: 도형을 한 번만 그려 이미지로 쓰는 도우미(그리기 비용 절감)
- `src/game/playTime.ts`: 쉬어 가기 안내용 놀이 시간
- `src/audio/engine.ts`: 효과음·음악이 함께 쓰는 오디오 장치, 첫 터치 잠금 해제, 일시 정지
- `src/audio/Sfx.ts`: 합성 효과음
- `src/audio/Music.ts`, `songs.ts`, `instruments.ts`: 배경음악 재생기, 곡 악보, 전통 악기풍 합성음
- `src/platform/webapp.ts`: 서비스 워커, 전체 화면, 방향 감지, 브라우저 제스처 차단

## 확인

```bash
npm run build
npm test
npm run test:full
```

`npm test`는 빠른 검사(약 7분)입니다. `npm run test:full`은 걷기와 점프만 하는 자동 플레이어가 12장을 실제로 끝까지 지나갈 수 있는지(지형에 갇히지 않는지)까지 확인합니다(5분 더).

처음 테스트할 때는 `npx playwright install chromium`이 필요합니다. 테스트는 별도 포트(기본 5174, `PW_PORT`로 변경)에서 개발 서버를 시작하고 종료합니다. 1~12장 전환과 엔딩, 장 제목 카드, 대화 중 정지와 연타 방지, 점프 버퍼, 체크포인트 재시작, 일시 정지, 이어하기 보호, 웹앱 매니페스트, 배경음악(장별 곡·보스 북·음량), 스마트폰 터치(두 손가락·버튼 사이 미끄러지기·공격 유지)와 세로 화면 안내, 장별 지형 규칙, 근두운, 조작 안내, 별과 장 고르기, 긴 폰 화면 채우기, 요괴 도감, 타격 밀림, 길 막대, 장 다시 하기와 대화 건너뛰기, 동료의 말과 도움, 쉬어 가기 안내를 검증합니다.

개발 서버의 `?stage=stage-03` 주소로 원하는 장을 미리 볼 수 있습니다. 미리보기의 레벨·동료·여의봉 진행은 메모리에서만 유지되며 실제 저장 기록을 바꾸지 않습니다. 배포본에서는 이 개발 기능이 비활성화됩니다.

## 이미지와 배포

원본 그림은 `art-source`에 있고 배포되지 않습니다. `npm run art:optimize`가 게임에서 받는 크기로 줄인 파일을 `public`에 만듭니다.

- 배경: 원본 PNG(28 MB) → WebP(2.9 MB)
- 손오공 스프라이트: 원본 1224~1536 px(5 MB) → 높이 320 px WebP(0.1 MB). 화면에 약 140 px로 그려지므로 화질 차이는 없고, 큰 텍스처를 줄일 때 생기던 계단 현상도 줄어듭니다. 웅크린 자세의 흰 배경은 이 단계에서 미리 지웁니다.
- 캐릭터 48종: `art-source/characters`의 PNG(2.6 MB) → WebP(0.6 MB). 투명도는 그대로이고 2배로 확대해도 차이가 보이지 않습니다. 처음 화면이 뜨기 전에 받는 그림이 약 3.1 MB에서 0.75 MB로 줄었습니다.
- 앱 아이콘: 192, 512, 마스커블 512, Apple 터치 아이콘 180

캐릭터 그림표 가공은 `npm run art:prepare`이며, 결과 PNG는 `art-source/characters`에 저장됩니다. 쓰이지 않던 예전 몬스터·스프라이트 시트는 `art-source/legacy`로 옮겼습니다.

Vercel은 Vite 프로젝트로 `npm run build`를 실행하고 `dist`를 배포합니다. 환경변수나 서버 데이터베이스가 필요하지 않습니다. 진행 상황은 각 브라우저의 localStorage에 저장되므로 다른 기기로 자동 동기화되지 않습니다.

검토 기록: [docs/review.md](docs/review.md). 이미지 제작 기록: [art-source/README.md](art-source/README.md).

## 추가 아케이드 구간

- **2장·9장 미로**: 위아래 갈림길에서 빛나는 인장 3개를 찾아 문을 엽니다. 오른쪽 미니맵에서 남은 인장을 확인하며, 재도전에도 찾은 인장은 남습니다.
- **4장 번개 회피**: `!`가 표시된 자리에 1초 뒤 번개가 떨어집니다. 옆으로 피하고, 20초를 버틴 뒤 오른쪽 구름문으로 탈출합니다.
- **8장 근두운 레이싱**: 출발 구름부터 결승까지 자동으로 날아갑니다. `↑/W` 또는 점프 버튼을 누르면 올라가고, 떼면 내려갑니다. `→/D`는 가속, `←/A`는 감속. 18초 안에 황금 링 4개 이상을 모으면 추가 보상을 받습니다. 결승 뒤에는 평소 걷기·점프·공격으로 돌아옵니다.
- 완료 화면에는 미로 인장, 번개 회피 횟수, 근두운 시간·링 수를 표시합니다. 모든 도전은 대화와 일시 정지 중에 멈춥니다.

황금 여의봉은 강화 전용 자세 그림 4종으로 표시하며, 12장 모두 배경 장식과 원경·전경, 지형 텍스처, 주변 입자를 사용합니다. 배포 애셋의 누락·투명도는 `npm run art:verify`로 확인할 수 있습니다. 원본 PNG는 `art-source/sprites`, 게임용 WebP는 `public/assets/sprites`에 있습니다.
