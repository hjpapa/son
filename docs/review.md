# 전체 게임 검토와 보완

## 서사

12장을 유지하며 원인과 결과를 강화했습니다. 힘을 얻음 → 천궁에서의 잘못 → 오행산에서의 반성 → 스승과 동료에게 한 약속 → 도움을 구하고 함께 걸음 → 불경을 나눔으로 이어집니다. 시작과 끝에만 있던 이야기 사이에 길 중간 대화, 보스 만남, 승리 후 해결 대화를 연결했습니다.

초등학교 1학년이 한 번에 읽을 수 있도록 대사를 짧게 나눴습니다. 대화창은 화자의 그림을 보여 주고 긴 내용은 3줄씩 자동으로 페이지를 나눕니다. 읽는 동안 물리 엔진을 멈추므로 적과 발사체가 접근하지 않습니다.

원작 대조: [서유기 원문 목차](https://zh.wikisource.org/wiki/西遊記), [15회 백룡마](https://zh.wikisource.org/wiki/西遊記/第015回), [21회 영길보살과 황풍괴](https://zh.wikisource.org/wiki/西遊記/第021回). 기존 게임의 장 순서를 유지해 사오정 합류와 황풍대왕 사건의 배치는 원작 순서와 다릅니다. 옥수수 탄생, 수문장 시험과 후반 3개 시련은 창작 각색으로 구분합니다.

## 시각적 통일

일반 몬스터 33종, 보스 9종, 동료 3명, 주요 NPC 3명을 손오공의 외곽선·눈·채색에 맞춰 제작했습니다. 이전의 도형 얼굴과 사실적인 몬스터 이미지 대신 스테이지 이름에 맞는 고유 캐릭터를 표시합니다. 충돌 상자를 새 스프라이트 크기에 맞췄고 원본 비율을 보존합니다. 배경은 WebP로 압축하여 모바일 전송량을 줄입니다.

## 수정한 동작

- 대화 중 적의 움직임과 공격이 계속되던 문제, 다음 장 종료 처리 오류 수정.
- 충돌 콜백과 범위 검사에서 한 공격이 중복 적중하던 문제 수정.
- 미리보기에서 경험치·동료·여의봉이 다음 장에 반영되지 않던 문제 수정. 실제 저장과 분리된 메모리 진행 사용.
- 첫 장 완료 전 얻은 경험치도 이어하기 대상으로 인식.
- 모바일에서 한 손가락을 떼면 다른 손가락의 이동도 풀리던 문제 수정.
- 긴 대사 페이지 분할, 인물 초상 추가.
- 레벨 증가로 평상시 흰 봉이 생기는 회귀가 없는지 검증.

## 검증 범위

자동 브라우저 테스트는 위치를 준비한 뒤 실제 공격 키와 충돌 처리를 사용해 보스를 상대합니다. 1~12장 출구 전환, 수문장 이후 여의봉, NPC 만남과 불경, 엔딩을 확인합니다. 시작부터 끝까지 사람이 연속으로 조작하는 난이도 검증을 대신하지는 않습니다. 각 장과 모바일 화면을 캡처해 별도로 시각 확인합니다.

현재 게임은 짧은 12장으로 구성된 어린이용 각색입니다. 원작 100회의 전체 사건, 음성 읽기, 배경음악, 기기 간 저장 동기화는 이번 구현 범위에 포함되지 않습니다.
