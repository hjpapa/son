### 스마트폰·태블릿 웹앱

- 매니페스트, 아이콘, 테마 색, iOS 홈 화면 메타 태그. 가로 전체 화면으로 설치.
- 서비스 워커: 페이지는 네트워크 우선, 파일은 캐시 우선 후 백그라운드 갱신. 12장 배경을 미리 받아 오프라인 플레이.
- 세로 화면 안내와 자동 정지, 앱 전환 시 일시 정지 메뉴, 노치 안전 영역, 확대·당겨서 새로고침 차단.
- 터치 버튼: 5개 → 4개(웅크리기는 어떤 공격도 피하지 못해 뺌), 반지름 34 → 54~64 px, 글꼴에 없을 수 있는 `⚔` 대신 그림 아이콘. 버튼 사이 미끄러지기, 공격 버튼 길게 누르기. 키보드만 있는 기기에서는 숨김.
- Phaser를 별도 파일로 나눠 게임 수정 후에도 캐시 유지.

### 초등학교 1~2학년 눈높이

- 대화 글자 20 → 25 px, HUD 글자 15 → 17~23 px. 폰(844×390)에서도 실제 글자 크기 약 12 px 이상.
- 하트·구름·동료 얼굴로 상태 표시, 1장은 `코인 3 / 5`처럼 목표 수를 보여 줌.
- 점프 여유 시간(110 ms)과 점프 입력 기억(150 ms).
- 구름 부적 1 → 2개, 실패 시 체크포인트에서 재시작(이미 본 대화·모은 코인 유지).
- 보스 특수 공격 간격 4.3/3.1초 → 4.7/3.5초, 번개 경고 0.82 → 0.95초와 `!` 표시.
- 위험 지형 이름표, 바람이 불기 직전 "휘이잉~" 알림, 코인을 다 모으면 갈 방향 안내.
- 목표 문장을 짧게("~하세요" → "~해요!").
- 사람 목소리로 읽어 주는 기능은 넣지 않았습니다.
- 배경음악은 효과음보다 작게 섞었습니다. 모든 곡을 미리 렌더링해 최고 음량 0.11~0.20(효과음과 겹쳐도 찌그러지지 않음), 평균 약 −30 dB로 고르게 맞췄고 테스트로 확인합니다.

- 원숭이 친구(1장), 동해 용왕(3장), 관음보살(5·12장)이 이야기 속 장소에 서 있음.
- 원작 장면 보강: 수보리 조사의 일흔두 가지 변신, 부처님 손바닥의 다섯 기둥, 관음보살의 약속, "제천대성".

- 배경음악(추가): 처음 화면, 12장, 클리어 화면, 엔딩에 15곡. 숫자 악보로 쓴 5음계 가락을 대금·가야금·편종·북·목탁풍 합성음으로 연주. 보스 근처에서는 전투 북이 더해짐. 음원 파일 0 MB.

## 1차 검토

### 서사

12장을 유지하며 원인과 결과를 강화했습니다. 힘을 얻음 → 천궁에서의 잘못 → 오행산에서의 반성 → 스승과 동료에게 한 약속 → 도움을 구하고 함께 걸음 → 불경을 나눔으로 이어집니다. 시작과 끝에만 있던 이야기 사이에 길 중간 대화, 보스 만남, 승리 후 해결 대화를 연결했습니다.

초등학교 1학년이 한 번에 읽을 수 있도록 대사를 짧게 나눴습니다. 대화창은 화자의 그림을 보여 주고 긴 내용은 3줄씩 자동으로 페이지를 나눕니다. 읽는 동안 물리 엔진을 멈추므로 적과 발사체가 접근하지 않습니다.

원작 대조: [서유기 원문 목차](https://zh.wikisource.org/wiki/西遊記), [15회 백룡마](https://zh.wikisource.org/wiki/西遊記/第015回), [21회 영길보살과 황풍괴](https://zh.wikisource.org/wiki/西遊記/第021回). 기존 게임의 장 순서를 유지해 사오정 합류와 황풍대왕 사건의 배치는 원작 순서와 다릅니다. 옥수수 탄생, 수문장 시험과 후반 3개 시련은 창작 각색으로 구분합니다.

### 시각적 통일

일반 몬스터 33종, 보스 9종, 동료 3명, 주요 NPC 3명을 손오공의 외곽선·눈·채색에 맞춰 제작했습니다. 이전의 도형 얼굴과 사실적인 몬스터 이미지 대신 스테이지 이름에 맞는 고유 캐릭터를 표시합니다. 충돌 상자를 새 스프라이트 크기에 맞췄고 원본 비율을 보존합니다. 배경은 WebP로 압축하여 모바일 전송량을 줄입니다.

### 수정한 동작

- 대화 중 적의 움직임과 공격이 계속되던 문제, 다음 장 종료 처리 오류 수정.
- 충돌 콜백과 범위 검사에서 한 공격이 중복 적중하던 문제 수정.
- 미리보기에서 경험치·동료·여의봉이 다음 장에 반영되지 않던 문제 수정. 실제 저장과 분리된 메모리 진행 사용.
- 첫 장 완료 전 얻은 경험치도 이어하기 대상으로 인식.
- 모바일에서 한 손가락을 떼면 다른 손가락의 이동도 풀리던 문제 수정.
- 긴 대사 페이지 분할, 인물 초상 추가.
- 레벨 증가로 평상시 흰 봉이 생기는 회귀가 없는지 검증.

### 검증 범위

자동 브라우저 테스트는 위치를 준비한 뒤 실제 공격 키와 충돌 처리를 사용해 보스를 상대합니다. 1~12장 출구 전환, 수문장 이후 여의봉, NPC 만남과 불경, 엔딩을 확인합니다. 시작부터 끝까지 사람이 연속으로 조작하는 난이도 검증을 대신하지는 않습니다. 각 장과 모바일 화면을 캡처해 별도로 시각 확인합니다.

현재 게임은 짧은 12장으로 구성된 어린이용 각색입니다. 원작 100회의 전체 사건, 음성 읽기, 배경음악, 기기 간 저장 동기화는 이번 구현 범위에 포함되지 않습니다.

## 5차 보완 (2026-10-04): 강화 아트와 아케이드 구간

- 황금 여의봉의 대기·달리기·공격·웅크림 PNG 4종을 내장 image_gen으로 제작하고 WebP로 배포합니다. 붉은 봉 몸통과 황금 장식은 모든 자세에서 손 안에 들어갑니다. 기존 봉 위에 길게 그리던 강화 선을 없애고, 실제 공격 판정 끝에 짧은 타격 호만 표시합니다. 원본·강화 자세 모두 투명 영역을 정리해 자세 전환 때 크기가 달라지는 문제를 줄였습니다.
- 배경 원본 12장은 기존에 모두 존재했습니다. 이번 보완은 실제 게임에서 부족했던 층과 지형을 완성합니다. 장별 수정·나무·갈대·옥수수·구름·바위 장식, 느리게 움직이는 원경, 가까운 장식, 재사용 지형 텍스처, 최대 18개의 주변 입자를 추가했습니다. 장식은 충돌 지형과 구분됩니다.
- 2·9장: 아래 통로와 위쪽 갈림길을 오가는 미로. 인장 3개를 모으면 문이 올라가고 출구가 열립니다. 미니맵에서 손오공과 인장의 위치를 확인할 수 있습니다. 문을 점프로 우회해도 인장이 없으면 장을 완료할 수 없습니다. 인장과 열린 문은 체크포인트 재도전에도 유지합니다.
- 4장: 플레이어의 위치를 먼저 고정해 1초간 경고한 뒤 번개를 떨어뜨립니다. 옆으로 피하면 경험치와 회피 횟수를 얻습니다. 바닥의 기존 번개 지형도 대기·예고·낙하 시간으로 나눴습니다. 20초를 버틴 뒤 구름문까지 이동해야 탈출합니다.
- 8장: 출발 구름에 닿으면 근두운으로 비행합니다. 점프를 누르면 상승하고 놓으면 하강, 오른쪽은 가속, 왼쪽은 감속입니다. 황금 링 6개와 먹구름을 지나 결승에 도착하면 지상 조작과 발판 충돌이 돌아옵니다. 18초 안에 링 4개 이상이면 추가 경험치를 얻습니다. 완료 화면에는 시간과 링 수가 나옵니다.
- 대화·일시 정지 중에는 도전 시간, 인장·링 수집과 피해가 멈춥니다. 새 HUD는 보스 체력이나 튜토리얼과 동시에 겹쳐 나오지 않으며, 도전 알림은 화면 안의 정해진 위치에 표시합니다.
- 서비스 워커 캐시 버전을 v3으로 올렸습니다. 강화 애셋은 처음 로딩 때 받으므로 기존 오프라인 캐시 준비에 포함됩니다.

검증 명령은 `npm run art:verify`, `npm run build`, `npm run test:full`입니다. 애셋 검사는 배경 12장·손오공 자세 8종·캐릭터 48종의 파일과 투명도를 확인합니다. 새 회귀 검사는 미로 잠금·수집·재시작, 번개 경고 고정·정지·회피·직격, 근두운의 실제 키 입력·링 중복 방지·정지·착지를 검사합니다. 기존 12장 연속 진행과 이동·점프 경로 검사도 새 미로를 포함합니다.
